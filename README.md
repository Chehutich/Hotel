Hotel Management System (Система управління готелем)
Десктоп застосунок (Windows Forms) для автоматизації роботи адміністраторів та рецепціоністів готелю. Система дозволяє керувати бронюваннями, гостями, номерним фондом та формувати звіти.

*** ОСНОВНІ МОЖЛИВОСТІ ***
* Рольова модель доступу: Розмежування прав для Рецепціоніста та Адміністратора.
* Smart-бронювання: Автоматичний пошук вільних номерів за датами та місткістю, миттєвий розрахунок вартості проживання з урахуванням знижок.
* Життєвий цикл проживання: Фіксація фактичного заселення (Check-in) та виселення (Check-out) зі зміною статусів номерів.
* Управління номерним фондом: Контроль статусів ("Доступна", "Зайнята", "На прибиранні", "На ремонті").
* База гостей: Збереження історії, автоматична перевірка на дублікати, система лояльності ("Постійний клієнт").
* Персоналізація:
  * Двомовний інтерфейс (Українська / English).
  * Дві візуальні теми (Світла / Темна).
* Звітність: Генерація звітів у форматі XML/FastReport.

*** ТЕХНОЛОГІЇ ***
* Мова: C# (.NET 6/8/9)
* UI: Windows Forms (WinForms)
* Архітектура: Single Form Interface (SPA-подібна навігація через UserControls).
* База даних: MySQL.
* ORM: Entity Framework Core (Pomelo.EntityFrameworkCore.MySql).

*** НАЛАШТУВАННЯ ТА ЗАПУСК ***
1. Вимоги
* Встановлений .NET SDK.
* Встановлений MySQL Server.
* Visual Studio 2022 (або новіша).

2. Налаштування Бази Даних
* Перед першим запускум необхідно створити базу даних та наповнити її даними.
* Відкрийте файл БД.txt (знаходиться в корені проєкту).
* Скопіюйте SQL-скрипт та виконайте його у вашому клієнті MySQL (наприклад, MySQL Workbench). Це створить базу hotel, всі таблиці, процедури та тестові дані.

3. Конфігурація підключення (.env)
Проєкт використовує файл .env для безпечного зберігання налаштувань підключення. Переконайтеся, що файл .env знаходиться у папці, звідки запускається .exe файл (зазвичай bin\Debug\netX.X-windows), або у корені проєкту при запуску з Visual Studio.
Приклад вмісту .env:

DB_HOST=localhost 
DB_PORT=3306 
DB_NAME=hotel 
DB_USER=root 
DB_PASSWORD=password  <-- Вкажіть ваш пароль до MySQL

5. Запуск
Відкрийте файл рішення Hotel.sln у Visual Studio та натисніть Start (F5).

*** ДОСТУП (ЛОГІН І ПАРОЛЬ) ***
Для входу в систему використовуються попередньо створені облікові записи з різними правами доступу.
* Рецепціоніст: 
Логін - reception
Пароль - pass123
Опис прав - Бронювання, заселення/виселення, робота з гостями, зміна статусу кімнат.

* Адміністратор (НЕРЕАЛІЗОВАНІ ФУНКЦІЇ):
Логін - admin
Пароль - admin123
Опис прав - Повний доступ, включаючи управління персоналом та редагування типів номерів (в розробці).

*** СТРУКТУРА ПРОЄКТУ ***
Після рефакторингу файли проєкту організовані наступним чином:

* Forms/ — Основні вікна (Головна форма, Авторизація, Звіти).
* Buttons/ — UserControls (Екрани функціоналу: список гостей, створення броні тощо).
* Core/ — Ядро логіки (AppContext, ThemeManager).
* Models/ — Моделі бази даних (Entity Framework).
* Localization/ — Файли ресурсів для перекладу (.resx).
* Utils/ — Допоміжні класи (Серіалізація).
* images/ — Графічні ресурси та іконки.

*** ПРИМІТКА ***
Система використовує хешування паролів (SHA-256). Якщо ви хочете додати нового користувача вручну через БД, пароль має бути захешований.
